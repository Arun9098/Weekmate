Manage custom Schema.org structured data and JSON-LD markup from WordPress.

== Description ==

Custom Schema Manager allows administrators to create and manage custom structured data and JSON-LD schema markup.

== Installation ==

1. Upload the custom-schema-manager folder to the /wp-content/plugins/ directory.
2. Activate the plugin through the Plugins menu in WordPress.
3. Configure the plugin from the Custom Schema Manager settings page.

== Frequently Asked Questions ==

= Does this plugin support JSON-LD? =

Yes. The plugin supports JSON-LD structured data.
